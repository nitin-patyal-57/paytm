# Advertisement assets

Place a local MP4 promotional video at:

    assets/ads/promo.mp4

Requirements: H.264 MP4, ideally 5 seconds, ≤ 5 MB, landscape 1280x720.

A sample video is generated by the repository script (see the root README,
"Sample advertisement video"). If the file is missing the app automatically
shows the branded fallback advertisement for five seconds, so the demo still
works without it.
